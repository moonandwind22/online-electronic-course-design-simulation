封装语义

DIP 缺口、QFP 四边引脚、TO 系列散热片与极性标记均按行业常见表达绘制。

可编辑结构

独立 SVG 含 title、desc 与 pins/package/markings 等语义分组；大符号每脚附 data-pin 与 data-direction，无位图、脚本或外部依赖。

大符号规范

集成电路按标准脚序；开发板与模块采用功能端口，不为不同厂商版本虚构物理脚号；分立器件使用标准原理图符号。

主题变量

通过 --eda-ink、--eda-package、--eda-symbol-body、--eda-accent 等变量适配界面，默认色可直接使用。

尺寸建议

项目替换与文件结构

查看品牌与五个领域图标预览；独立文件位于 assets/current/ui/。

redesigned-design/electronic-lab/ 是已替换器件缩略图与原理图符号的完整 design 副本，可对照预览。

assets/current/ 对应当前项目器件；assets/extended/ 为后续扩展；assets/large-schematic/ 为其余器件的大符号版本；assets/schematic/schematic-symbols.svg 保留原 symbol id，可替换共享符号文件。

页面状态建议：默认使用当前主题色；悬停提高描边对比；选中仅增加外框，不改变器件本身极性与引脚颜色；禁用态整体不透明度 40%。器件命名使用“型号-封装”小写短横线。

所有图形均为可编辑 SVG。品牌型号仅用于器件识别，未绘制厂商商标；通用兼容板不代表官方开发板外观复刻。
